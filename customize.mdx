# <br />**Overview**

Personalize Xrypton's appearance in your server by setting a custom avatar, banner, and/or bio to make your community stand out.

<Info>
  Only the **server owner** can use these commands.
</Info>

# **Customizing Xrypton's avatar**

You can change Xrypton's avatar using the `customize avatar` command.

<CodeGroup>

```text Syntax
,customize avatar (image URL)
```

```text Example
,customize avatar https://bleed.bot/avatar.png
```

</CodeGroup>
